## 💡 核心功能详解

### 1. 网站图片同步

**功能说明**：
- 自动扫描`images/`文件夹下的所有图片
- 支持webp, jpg, jpeg, png格式
- 按命名规则识别图片（如`street-01.webp`）
- 实时显示扫描进度

**使用方法**：
```
管理图片 → 同步网站图片 → 等待完成
```

**识别的命名规则**：
- 街头摄影: `street-NN.ext`
- 纪实摄影: `doc-NN.ext`
- 自然风光: `nature-NN.ext`
- 人像摄影: `portrait-NN.ext`
- 城市景观: `city-NN.ext`
- 动物摄影: `animals-NN.ext`
- 静物摄影: `still-NN.ext`

（NN为01-99的编号，ext为文件扩展名）

### 2. 图片元数据编辑

**功能说明**：
- 修改图片标题、描述、分类
- 查看图片完整信息和预览
- 批量操作支持

**使用流程**：
1. 在图片列表中点击 **"编辑"**
2. 修改需要的信息
3. 点击 **"保存更改"**
4. 在弹窗中点击 **"确定"** 下载元数据
5. 将下载的`site-images-metadata.json`文件
6. 复制到项目的`data/`文件夹

**为什么需要手动更新文件？**
> 由于浏览器安全限制，JavaScript无法直接写入服务器文件。因此需要通过下载-替换的方式更新元数据。

### 3. 数据导出与备份

**功能说明**：
- 导出完整的元数据JSON文件
- 作为网站内容的备份
- 可用于恢复或迁移

**使用方法**：
```
备份恢复 → 导出数据 → 保存文件
```

### 4. 筛选和搜索

**功能说明**：
- 按分类筛选图片
- 关键词搜索（标题+描述）
- 网格/列表视图切换

**使用方法**：
- 使用顶部的分类下拉菜单
- 输入关键词搜索
- 点击视图切换按钮

### 5. 批量操作

**功能说明**：
- 选择多张图片
- 批量删除（从元数据）
- 批量修改分类（计划中）

**使用方法**：
1. 点击图片左上角复选框选择
2. 使用底部批量操作栏
3. 确认操作

## 🏗️ 技术架构

### 数据流图

```
主网站 (images/)
       ↓
    [扫描检测]
       ↓
元数据文件 (data/site-images-metadata.json)
       ↓
    [读取加载]
       ↓
Admin工具 (显示/编辑)
       ↓
    [修改保存]
       ↓
LocalStorage (临时缓存)
       ↓
    [导出下载]
       ↓
元数据文件 (更新) → 主网站读取
```

### 关键组件

1. **SiteSyncManager** (`site-sync-manager.js`)
   - 图片文件扫描
   - 元数据读取/写入
   - 命名规则匹配

2. **EnhancedImageManager** (`enhanced-image-manager.js`)
   - UI界面管理
   - 用户交互处理
   - 数据展示和编辑

3. **AdminUtils** (`admin-utils.js`)
   - 通用工具函数
   - 模态框管理
   - 提示消息

4. **元数据文件** (`site-images-metadata.json`)
   - JSON格式存储
   - 版本控制
   - 分类结构

### 数据结构

```json
{
  "version": "1.0",
  "lastUpdate": "2025-10-04T00:00:00.000Z",
  "images": {
    "street": [
      {
        "id": "street_1_1696406400000",
        "filename": "street-01.webp",
        "path": "../images/street/street-01.webp",
        "category": "street",
        "number": 1,
        "title": "街头摄影 1",
        "description": "",
        "uploadDate": "2025-10-04T00:00:00.000Z",
        "exists": true
      }
    ]
  },
  "categories": {
    "street": {
      "id": "street",
      "name": "街头摄影",
      "path": "../images/street/"
    }
  }
}
```

## 🔧 配置和定制

### 修改扫描规则

编辑`site-sync-manager.js`中的`namingPatterns`:

```javascript
this.namingPatterns = {
    'street': /^street-(\d+)\.(webp|jpg|jpeg|png)$/i,
    // 添加或修改其他规则
};
```

### 修改分类

1. 更新`data/site-images-metadata.json`中的`categories`
2. 更新`enhanced-image-manager.js`中的`getCategoryLabel()`
3. 更新`admin/index.html`中的分类选择器

### 自定义样式

编辑`admin/styles/admin.css`中的CSS变量:

```css
:root {
    --burberry-beige: #D4B896;
    --burberry-black: #000000;
    /* 修改这些变量 */
}
```

## 🛠️ 故障排除

### 常见问题

**Q: 点击同步没反应？**
A: 
1. 检查浏览器控制台（F12）
2. 确认本地服务器运行中
3. 尝试刷新页面重试

**Q: 扫描找不到图片？**
A:
1. 确认图片在正确的文件夹
2. 检查文件名是否符合命名规则
3. 确认文件扩展名正确

**Q: 修改后主网站没更新？**
A:
1. 确认已下载元数据文件
2. 确认已替换到data文件夹
3. 清除浏览器缓存（Ctrl+Shift+R）

**Q: 页面加载很慢？**
A:
1. 使用分类筛选
2. 检查网络连接
3. 考虑优化图片大小

### 错误码说明

- `HTTP 404`: 元数据文件不存在
- `HTTP 403`: 权限问题
- `CORS Error`: 跨域问题（确保使用HTTP服务器）
