# Admin工具快速开始指南

## 5分钟快速上手

### 第一步：启动服务器

在项目根目录打开终端，运行以下命令：

```bash
# Windows用户推荐使用Python
python -m http.server 8000

# 或者使用Node.js
npx http-server -p 8000
```

### 第二步：访问管理工具

在浏览器中打开：
```
http://localhost:8000/admin/
```

### 第三步：同步现有图片

1. 点击左侧菜单的 **"管理图片"**
2. 点击右上角的 **"🔄 同步网站图片"** 按钮
3. 等待扫描完成（10-30秒）
4. 完成！现在你可以看到所有主网站的图片了

## 常见操作

### 编辑图片信息

1. 找到要编辑的图片
2. 点击 **"编辑"** 按钮
3. 修改标题、描述或分类
4. 点击 **"保存更改"**
5. 在弹窗中点击 **"确定"** 下载更新的元数据
6. 用下载的 `site-images-metadata.json` 替换 `data/site-images-metadata.json`

### 查看图片详情

- 直接点击图片可查看大图和完整信息

### 搜索和筛选

- 使用顶部的 **分类筛选** 下拉菜单
- 使用 **搜索框** 按标题或描述搜索
- 切换 **网格/列表** 视图模式

### 批量操作

1. 点击图片左上角的 **复选框** 选择多张图片
2. 使用底部出现的批量操作栏
3. 支持批量删除等操作

## 重要提示

### ⚠️ 关于文件更新

由于浏览器安全限制，修改后需要手动下载并替换元数据文件。步骤：

1. 修改图片信息后，会弹出提示
2. 点击"确定"下载 `site-images-metadata.json`
3. 将下载的文件复制到项目的 `data/` 文件夹
4. 替换原有的 `site-images-metadata.json` 文件
5. 刷新主网站查看更新

### 📝 关于图片文件

- Admin工具**不会删除或移动**实际的图片文件
- "删除"操作只是从元数据列表中移除
- 实际图片文件需要手动管理

### 💡 图片命名规则

新图片请按以下格式命名：

- 街头摄影: `street-01.webp`, `street-02.jpg`
- 纪实摄影: `doc-01.webp`, `doc-02.jpg`
- 自然风光: `nature-01.webp`, `nature-02.jpg`
- 人像摄影: `portrait-01.webp`, `portrait-02.jpg`
- 城市景观: `city-01.webp`, `city-02.jpg`
- 动物摄影: `animals-01.webp`, `animals-02.jpg`
- 静物摄影: `still-01.webp`, `still-02.jpg`

## 遇到问题？

### 页面空白或加载失败
- 检查浏览器控制台（按F12）查看错误
- 确认本地服务器正在运行
- 尝试清除浏览器缓存

### 同步找不到图片
- 确认图片在正确的文件夹（`images/分类名/`）
- 检查文件名是否符合命名规则
- 支持的格式：webp, jpg, jpeg, png

### 修改不生效
- 确认已下载并替换元数据文件
- 刷新浏览器（Ctrl + Shift + R）
- 检查文件路径是否正确
