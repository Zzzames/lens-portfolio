# Admin工具升级指南

## 更新概述

本次更新实现了admin管理工具与主网站之间的完整数据同步功能，解决了以下核心问题：

### 解决的问题
1. ✅ **无法查看主网站内容** - 现在可以扫描并同步主网站images文件夹中的所有图片
2. ✅ **修改无法生效** - 修改后可导出元数据文件，更新到主网站
3. ✅ **数据隔离** - 使用统一的JSON元数据文件管理图片信息

## 新增功能

### 1. 网站图片同步
- 点击"同步网站图片"按钮，自动扫描`images/`文件夹
- 支持所有7个分类的图片检测
- 实时显示同步进度
- 自动识别图片文件（webp, jpg, jpeg, png）

### 2. 统一元数据管理
- 使用`data/site-images-metadata.json`存储所有图片元数据
- 包括标题、描述、分类、上传日期等信息
- 支持导出更新后的元数据

### 3. 增强的编辑功能
- 编辑图片标题、描述、分类
- 查看图片完整信息
- 批量操作支持

## 使用流程

### 首次使用

1. **启动本地服务器**
   ```bash
   # 使用Python（推荐）
   python -m http.server 8000
   
   # 或使用Node.js
   npx http-server -p 8000
   ```

2. **访问管理工具**
   ```
   http://localhost:8000/admin/
   ```

3. **同步现有图片**
   - 点击"管理图片"菜单
   - 点击"同步网站图片"按钮
   - 等待扫描完成（通常需要10-30秒）
   - 查看同步到的所有图片

### 日常使用

#### 编辑图片信息
1. 在"管理图片"页面找到要编辑的图片
2. 点击"编辑"按钮
3. 修改标题、描述或分类
4. 点击"保存更改"
5. 在弹出的提示中选择"确定"下载更新的元数据文件
6. 将下载的`site-images-metadata.json`文件替换项目中的`data/site-images-metadata.json`

#### 批量操作
1. 选择多张图片（点击图片左上角的复选框）
2. 使用批量操作栏进行操作
3. 同样需要下载并更新元数据文件

#### 备份数据
1. 点击"备份恢复"菜单
2. 点击"导出数据"下载完整的元数据备份

## 重要说明

### 1. 元数据文件的作用
`data/site-images-metadata.json`文件存储了所有图片的元信息：
- 图片标题和描述
- 分类归属
- 文件名和路径
- 上传时间

### 2. 为什么需要手动下载更新？
由于浏览器安全限制，前端JavaScript无法直接修改服务器上的文件。因此：
- 所有修改先保存到浏览器的localStorage
- 通过下载功能获取更新后的JSON文件
- 手动替换服务器上的文件

### 3. 图片文件本身的管理
- Admin工具**不会**修改或删除实际的图片文件
- 删除操作只是从元数据中移除记录
- 实际图片文件需要手动通过FTP或文件管理器操作

### 4. 图片命名规则
系统识别以下命名格式的图片：
- 街头摄影: `street-01.webp`, `street-02.jpg`, ...
- 纪实摄影: `doc-01.webp`, `doc-02.jpg`, ...
- 自然风光: `nature-01.webp`, `nature-02.jpg`, ...
- 人像摄影: `portrait-01.webp`, `portrait-02.jpg`, ...
- 城市景观: `city-01.webp`, `city-02.jpg`, ...
- 动物摄影: `animals-01.webp`, `animals-02.jpg`, ...
- 静物摄影: `still-01.webp`, `still-02.jpg`, ...

## 最佳实践

### 1. 定期同步
- 每次添加新图片后，在admin工具中点击"同步网站图片"
- 建议每周备份一次元数据

### 2. 命名规范
- 新图片按照现有命名规则命名
- 编号连续，方便管理

### 3. 备份策略
- 每次重大修改前先导出备份
- 保存多个历史版本的元数据文件

### 4. 测试流程
- 修改后先在本地测试
- 确认无误后再替换生产环境的元数据文件

## 故障排除

### 问题1：同步时找不到图片
**原因**：图片文件不存在或命名不符合规则
**解决**：
- 检查图片文件是否在正确的目录
- 确认文件名符合命名规则
- 检查文件扩展名（webp, jpg, jpeg, png）

### 问题2：修改后主网站没有更新
**原因**：没有更新元数据文件或浏览器缓存
**解决**：
- 确认已下载并替换`data/site-images-metadata.json`
- 清除浏览器缓存或硬刷新（Ctrl+Shift+R）

### 问题3：页面加载很慢
**原因**：图片过多或网络问题
**解决**：
- 使用分类筛选减少显示的图片数量
- 检查网络连接
- 考虑优化图片大小

### 问题4：无法访问admin工具
**原因**：服务器未启动或端口被占用
**解决**：
- 确认本地服务器正在运行
- 尝试更换端口
- 检查防火墙设置
