# 个人信息管理功能使用说明

## 功能概述

个人信息管理功能允许用户轻松管理网站的个人资料，包括头像、背景图片、基本信息、品牌Logo和社交媒体链接。所有更改都会实时预览，并可以保存到本地存储中。

## 功能特性

### 1. 头像管理
- **上传头像**：支持JPG、PNG、WebP格式，最大5MB
- **图片裁剪**：提供多种裁剪比例（1:1、16:9、4:3、3:2）
- **实时预览**：上传后立即在预览区域显示效果

### 2. 背景图片管理
- **上传背景**：支持各种图片格式
- **灵活裁剪**：可自由调整裁剪区域
- **背景适配**：自动适配不同屏幕尺寸

### 3. 基本信息编辑
- **姓名**：支持中英文输入
- **个人简介**：两段式简介，支持多行文本
- **实时预览**：输入时即时更新预览效果

### 4. 品牌Logo管理
- **添加Logo**：支持上传多个品牌Logo
- **Logo删除**：可随时删除不需要的Logo
- **Logo显示**：在个人资料中优雅展示

### 5. 社交媒体链接
- **多平台支持**：微博、微信、Instagram、Twitter、Facebook、个人网站
- **动态添加**：可添加多个社交媒体链接
- **灵活管理**：支持添加和删除操作

## 使用步骤

### 1. 访问个人信息管理
1. 打开管理工具：`http://localhost:8080/index.html`
2. 点击左侧导航栏的"个人信息"菜单
3. 进入个人信息管理界面

### 2. 管理头像
1. 在"图片设置"区域找到头像部分
2. 点击"更换头像"按钮
3. 选择图片文件（支持JPG、PNG、WebP格式）
4. 在裁剪模态框中调整裁剪区域
5. 选择合适的裁剪比例（推荐1:1）
6. 点击"确认裁剪"完成头像设置

### 3. 设置背景图片
1. 在"图片设置"区域找到背景图片部分
2. 点击"添加背景"或"更换背景"按钮
3. 选择图片文件
4. 在裁剪模态框中调整裁剪区域
5. 可选择自由裁剪或固定比例
6. 点击"确认裁剪"完成背景设置

### 4. 编辑基本信息
1. 在"基本信息"区域填写姓名
2. 编辑第一段个人简介
3. 编辑第二段个人简介（可选）
4. 所有更改会实时反映在预览区域

### 5. 管理品牌Logo
1. 在"品牌Logo"区域查看现有Logo
2. 点击"+"区域添加新Logo
3. 选择Logo图片文件
4. 如需删除，点击Logo下方的"删除"按钮

### 6. 添加社交媒体链接
1. 在"社交媒体链接"区域选择平台
2. 输入对应的链接地址
3. 点击"添加社交媒体链接"添加更多链接
4. 点击"删除"按钮移除不需要的链接

### 7. 保存个人信息
1. 完成所有编辑后，点击"保存个人信息"按钮
2. 系统会显示保存成功的提示
3. 所有数据将保存到浏览器本地存储

### 8. 重置更改
1. 如需放弃所有未保存的更改
2. 点击"重置更改"按钮
3. 确认重置操作

## 技术特性

### 图片处理
- **自动压缩**：上传的图片会自动压缩优化
- **格式支持**：支持JPG、PNG、WebP等主流格式
- **尺寸限制**：最大支持5MB文件
- **裁剪功能**：提供多种裁剪比例选择

### 数据存储
- **本地存储**：使用浏览器localStorage保存数据
- **实时预览**：所有更改即时反映在预览区域
- **数据持久化**：刷新页面后数据依然保留

### 响应式设计
- **多设备适配**：支持桌面、平板、手机等设备
- **自适应布局**：根据屏幕尺寸自动调整布局
- **触摸友好**：支持触摸操作

## 常见问题

### Q: 上传的图片显示模糊怎么办？
A: 系统会自动压缩图片以优化性能，建议上传高分辨率图片以获得最佳效果。

### Q: 如何恢复到默认设置？
A: 点击"重置更改"按钮可以恢复到上次保存的状态，如需完全重置，请清除浏览器本地存储。

### Q: 个人信息会同步到主页面吗？
A: 目前个人信息保存在管理工具的本地存储中，如需同步到主页面，需要额外的数据同步机制。

### Q: 支持哪些图片格式？
A: 支持JPG、JPEG、PNG、WebP等主流图片格式。

### Q: 裁剪功能如何使用？
A: 上传图片后会自动打开裁剪模态框，可以拖拽调整裁剪区域，拖拽角落调整大小，选择合适的比例后确认裁剪。
