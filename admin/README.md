# 图片管理工具

一个功能完善的图片管理工具，用于自助管理网站内容，支持图片上传、编辑、分类管理和数据备份等功能。

## 功能特性

### 📤 图片上传
- 支持拖拽上传和点击选择文件
- 批量上传多张图片
- 自动图片压缩和格式优化
- 实时上传进度显示
- 文件类型和大小验证

### 📁 图片管理
- 网格和列表两种视图模式
- 图片信息编辑（标题、分类、描述）
- 图片预览和删除
- 批量选择和操作
- 分类筛选和关键词搜索

### 🏷️ 分类管理
- 预设7种图片分类（街头摄影、纪实摄影、自然风光等）
- 分类统计和管理
- 灵活的分类系统

### 💾 数据管理
- 本地存储图片元数据
- 数据导入导出功能
- 自动备份机制
- 数据恢复功能

### 🎨 用户体验
- 响应式设计，支持移动端
- 简洁专业的管理界面
- 与现有网站风格保持一致
- 流畅的交互动画
- 友好的操作提示

## 使用方法

### 1. 启动服务器

由于使用了本地存储和文件API，需要通过HTTP服务器访问：

```bash
# 使用Python启动简单服务器
python -m http.server 8000

# 或使用Node.js
npx http-server

# 或使用PHP内置服务器
php -S localhost:8000
```

### 2. 访问管理工具

在浏览器中访问：
```
http://localhost:8000/admin/
```

### 3. 基本操作

#### 上传图片
1. 点击"上传图片"菜单
2. 拖拽图片到上传区域或点击选择文件
3. 填写图片信息（标题、分类、描述）
4. 点击"保存图片"

#### 管理图片
1. 点击"管理图片"菜单
2. 使用筛选和搜索功能查找图片
3. 点击图片进行预览
4. 使用编辑按钮修改图片信息
5. 使用删除按钮移除不需要的图片

#### 批量操作
1. 在管理界面选择多张图片
2. 使用批量操作栏进行批量删除或修改分类

#### 数据备份
1. 点击"备份恢复"菜单
2. 使用"导出数据"按钮下载备份文件
3. 使用"导入数据"按钮恢复之前的备份

## 技术实现

### 前端技术
- HTML5 File API 处理文件上传
- Canvas API 实现图片压缩
- LocalStorage 存储图片元数据
- CSS3 动画和响应式设计
- 原生JavaScript实现所有功能

### 数据结构

#### 图片对象
```json
{
  "id": "img_1696406400000_abc123def",
  "filename": "street-01.jpg",
  "dataURL": "data:image/jpeg;base64,...",
  "size": 1024000,
  "type": "image/jpeg",
  "uploadDate": "2023-10-04T10:00:00.000Z",
  "title": "城市街头",
  "category": "street",
  "description": "繁华的城市街头..."
}
```

#### 分类系统
- street: 街头摄影
- documentary: 纪实摄影
- nature: 自然风光
- portrait: 人像摄影
- cityscape: 城市景观
- animals: 动物摄影
- stilllife: 静物摄影

## 注意事项

1. **文件大小限制**: 单个图片文件不超过10MB
2. **支持格式**: JPEG、PNG、WebP
3. **本地存储**: 浏览器本地存储有容量限制
4. **数据备份**: 建议定期导出数据进行备份
5. **服务器要求**: 需要通过HTTP服务器访问，不支持直接打开HTML文件

## 故障排除

### 常见问题

1. **无法上传图片**
   - 检查文件格式是否支持
   - 确认文件大小不超过限制
   - 确保通过HTTP服务器访问

2. **数据丢失**
   - 检查浏览器是否清除了本地存储
   - 使用导入功能恢复备份数据

3. **界面显示异常**
   - 刷新页面重试
   - 检查浏览器控制台错误信息
   - 确认CSS文件加载正常
